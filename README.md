# Faith CV Builder

Android CV/Resume Builder App with AI Assistant

## Setup Instructions

1. Open Android Studio
2. Select "Open an existing project"
3. Navigate to this folder (/home/mrteesoft/Documents/faith)
4. Click "OK" to import the project
5. Wait for Gradle sync to complete
6. Update local.properties with your Android SDK path
7. Run the app

## Features

- Splash Screen
- Welcome Screen  
- Main Dashboard
- Template Selection
- CV Form (Personal Info)
- CV Preview
- SQLite Database

## Architecture

- MVVM Pattern
- Material Design
- SQLite Database
- Fragment Navigation
