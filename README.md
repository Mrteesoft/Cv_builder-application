# CV Builder AI - Android App

Professional AI-powered CV/Resume builder with templates, form guidance, PDF export, and AdMob monetization.

## 🚀 Features

- **AI Assistant** - Get help with CV content and suggestions
- **Professional Templates** - Modern, Classic, and Elegant designs
- **Form Guidance** - Step-by-step CV creation process
- **PDF Export** - Generate professional PDF resumes
- **Responsive Design** - Optimized for phones and tablets
- **AdMob Integration** - Banner and interstitial ads for monetization

## 📱 App Details

- **Package**: `com.mrteesoft.cvbuilderai`
- **Version**: 1.1.0 (Version Code 4)
- **Min SDK**: 24 (Android 7.0)
- **Target SDK**: 34 (Android 14)

## 🛠️ Technical Stack

- **Language**: Java
- **Architecture**: MVVM Pattern
- **Database**: SQLite
- **PDF Generation**: iText7
- **Ads**: Google AdMob
- **UI**: Material Design
- **Build**: Gradle

## 📦 Dependencies

```gradle
implementation 'androidx.appcompat:appcompat:1.6.1'
implementation 'com.google.android.material:material:1.10.0'

```

## 🎯 Key Components

### Activities
- `SplashActivity` - App launch screen
- `MainActivity` - Dashboard with templates and AI assistant
- `PersonalInfoActivity` - Personal information form
- `CVPreviewActivity` - Professional CV preview
- `AIAssistantActivity` - AI chat interface

### Features
- **Multi-device support** - Phone and tablet layouts
- **Sans-serif typography** - Clean, professional fonts
- **Production ads** - Real AdMob revenue generation
- **Photo picker** - Privacy-compliant image selection
- **Storage Access Framework** - Modern file handling

## 🔧 Build Instructions

1. Clone the repository
2. Open in Android Studio
3. Sync Gradle files
4. Build and run

```bash
./gradlew assembleDebug
```
